## structure

```
d0thfiles/
├── bin/          # scripts & utilities
├── foot/         # terminal config
├── mango/        # window manager config
├── nvim/         # neovim config (lua)
├── rofi/         # launcher theme
├── swaync/       # notification daemon
├── wal/
│   └── templates/ # pywal color templates
├── waybar/       # status bar
└── yazi/         # file manager config
```

## install

> No automated install script yet. Stow or symlink manually.

```bash
git clone https://github.com/astxr0th/d0thfiles ~/.dotfiles
cd ~/.dotfiles

# copy the files to the right directory
cp -r ~/d0thfiles/* ~/.config/
```

Repeat for each component you want. Make sure the relevant packages are installed first.

## dependencies

```
foot  mango  neovim  rofi  yazi  waybar  swaync  python-pywal
```

Install on Arch:

```bash
paru -S foot mangowm-git neovim rofi yazi waybar swaync python-pywal
```
## keybindings
 
### apps & system
 
| keybind | action |
|---|---|
| `SUPER + Space` | rofi launcher |
| `SUPER + Return` | foot terminal |
| `SUPER + E` | yazi file manager |
| `SUPER + B` | helium browser |
| `SUPER + SHIFT + C` | edit mango config in nvim |
| `SUPER + SHIFT + Space` | toggle swaync notification panel |
| `SUPER + SHIFT + R` | screen recorder (wf-recorder) |
| `SUPER + R` | reload mango config |
| `SUPER + SHIFT + Q` | exit mango |
| `SUPER + Q` | kill focused client |
 
### window focus & swap
 
| keybind | action |
|---|---|
| `SUPER + Tab` | focus next window |
| `ALT + ←↑↓→` | focus window by direction |
| `SUPER + SHIFT + ←↑↓→` | swap window by direction |
 
### window state
 
| keybind | action |
|---|---|
| `SUPER + F` | fullscreen |
| `SUPER + SHIFT + F` | fake fullscreen |
| `SUPER + S` | toggle float |
| `SUPER + G` | toggle global |
| `ALT + Tab` | toggle overview |
| `ALT + A` | maximize screen |
| `SUPER + I` | minimize |
| `SUPER + SHIFT + I` | restore minimized |
| `SUPER + O` | toggle overlay |
| `ALT + SHIFT + Z` | toggle scratchpad |
 
### layout
 
| keybind | action |
|---|---|
| `SUPER + N` | switch layout |
| `ALT + E` | set proportion 1.0 |
| `ALT + X` | cycle proportion preset |
 
### tags (workspaces)
 
| keybind | action |
|---|---|
| `SUPER + 1–9` | switch to tag |
| `SUPER + SHIFT + 1–9` | move client to tag |
| `SUPER + →` / `SUPER + ←` | navigate tags right/left |
| `CTRL + →` / `CTRL + ←` | navigate tags (with client) |
| `CTRL + SUPER + →/←` | move tag right/left |
 
### monitor
 
| keybind | action |
|---|---|
| `ALT + SHIFT + ←/→` | focus monitor left/right |
| `SUPER + ALT + ←/→` | move tag to monitor |
 
### move & resize (floating)
 
| keybind | action |
|---|---|
| `CTRL + SHIFT + ←↑↓→` | move window by 50px |
| `CTRL + ALT + ←↑↓→` | resize window by 50px |
| `SUPER + drag (LMB)` | move window |
| `SUPER + drag (RMB)` | resize window |
 
### gaps
 
| keybind | action |
|---|---|
| `ALT + SHIFT + X` | increase gaps |
| `ALT + SHIFT + Z` | decrease gaps |
| `ALT + SHIFT + R` | toggle gaps |
